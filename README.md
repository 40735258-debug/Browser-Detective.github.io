## About

Having a strong interest in both creative problem-solving and modern web development, I wanted to design a project that offered something more unique than a traditional website. Instead of creating a standard application built around buttons, forms, and simple navigation, I explored how the browser itself could become part of the user experience. This idea inspired the creation of **The Browser Detective – The Case of the Hidden Web**, an interactive mystery puzzle built using HTML, CSS, and JavaScript.

The Browser Detective transforms a normal webpage into an investigation environment where the player becomes the detective. Rather than relying on visible instructions alone, users must inspect page elements, read source code, uncover hidden HTML comments, analyse CSS styling clues, and use JavaScript console commands to reveal evidence and progress through the game. Each stage increases in difficulty, encouraging users to think logically, pay attention to detail, and engage directly with the technologies that power the web. 

A major goal of this project was to demonstrate practical knowledge gained throughout the Web Technologies module in a creative and engaging format. The game applies key front-end development principles such as responsive design, DOM manipulation, event handling, conditional logic, structured navigation, and interactive user feedback. Instead of simply presenting technical features, the project turns them into gameplay mechanics that make learning more enjoyable and memorable. 

The project was also designed with future expansion in mind. Planned enhancements include player progress tracking, hint systems, scoreboards, database integration, and additional mystery cases with more advanced puzzles. This creates a scalable foundation that can continue to grow while maintaining a fun and immersive user experience. 

## Features

- Hidden HTML comments containing clues
- CSS-based visual puzzles and concealed elements
- JavaScript console interaction challenges
- Multi-level progression system
- Responsive design across devices
- Error handling and input validation
- Planned leaderboard and progress tracking system.
