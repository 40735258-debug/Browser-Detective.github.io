CASE 07 THE REFLECTION A drive that writes in the wrong direction.

// evidence inventory

Veyra kept one of his ciphers on a mirror drive. Mirror drives are a fringe hardware quirk: they record by inverted polarity, so every bit comes off the platter the opposite way round from how it went on. The output below is verbatim what the read-head produced. It is not broken. It is simply not meant to be read the way your eye is pointed.

// drive dump — mirror-00A
device :: MIRROR-00A
mode :: polarity-inverted
header :: 5A3B-Z
payload:: RORRIM_SSECCA
footer :: Z-B3A5
> read order: recorded right-to-left
